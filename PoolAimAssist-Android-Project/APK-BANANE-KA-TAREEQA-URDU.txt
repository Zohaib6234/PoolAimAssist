POOL AIM ASSIST — ANDROID APK BANANE KA ASAN TAREEQA

IMPORTANT:
- Is ZIP mein Android app ka source project hai; APK file pehle se shamil nahi.
- Is app ko compile karne ke liye GitHub Actions (online build) use hoga.
- App screen capture aur "Display over other apps" permission maangti hai.
- Ball detection basic color/blob algorithm par hai. Har table skin par perfect result ki guarantee nahi.
- App direct-shot guideline calculate karti hai; bank-shot reflection aur obstacle checking abhi implemented nahi.
- 8 Ball Pool/Miniclip ke rules third-party aim-assist ko mana kar sakte hain. Apne account ke risk par use karein.

MOBILE SE APK BANANE KE STEPS:
1. Chrome mein https://github.com kholein aur sign in karein.
2. New repository banayein. Naam: PoolAimAssist
3. Repository mein Add file > Upload files par tap karein.
4. Is ZIP ko pehle phone mein extract karein. Extracted PoolAimAssist-Android-Project folder ke ANDAR ki tamam files/folders upload karein. .github folder bhi zaroor upload karein.
5. Commit changes karein.
6. Repository ke Actions tab mein jayein.
7. "Build Android APK" workflow kholein. Agar push ke baad build start ho chuka ho to us run ko khol lein. Warna "Run workflow" dabayein.
8. Build complete hone par workflow run ke neeche Artifacts mein "PoolAimAssist-debug-apk" download karein.
9. Artifact ZIP ko phone mein extract karein.
10. app-debug.apk par tap karein. Android permission maange to sirf isi APK/source ke liye install permission allow karein.

APP START KARNE KE BAAD:
1. App kholein.
2. "Display over other apps" permission allow karein.
3. Screen capture prompt par Start now/Allow karein.
4. 8 Ball Pool kholein. Floating control panel se Calibrate dabayein.
5. Table ke 6 pockets ko ek ek karke tap karein. Calibration save ho jayegi.
6. Floating overlay mein shot guides nazar aani chahiye. Band karne ke liye Stop dabayein.

SAFETY:
- APK sirf apni banayi hui GitHub repository ke Actions artifact se install karein.
- Kisi unknown website ke modified APK ko install na karein.
- Screen capture permission dete waqt Android ka prompt dhyan se parhein.
